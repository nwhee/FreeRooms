# shadcn/ui patterns

- Components in `components/ui/` are generated by shadcn. Add new ones with
  `npx shadcn@latest add <name>`; don't hand-write them.
- Don't edit `components/ui/*` for one feature. Wrap it in a feature component in
  `components/<feature>/` instead.
- Compose: `Card`, `Dialog`, `Form` (react-hook-form + Zod), `Table`, `Sheet`,
  `DropdownMenu`, `Sonner` for toasts.
- Forms: `useForm` with `zodResolver`, the same Zod schema the server action uses.
- Use `cn()` from `lib/utils` to merge classes.
- Keep accessibility: every icon-only button gets an `aria-label`; dialogs have a
  title.
